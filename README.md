# Game Boy

Recriação interativa do Game Boy clássico com Next.js, TypeScript e Tailwind CSS.

## Funcionalidades

- Console com tela, D-pad, botões A/B, Select/Start, luz de bateria e alto-falante
- Switch OFF/ON, sons e controle de volume
- Sistema de cartuchos (Pokémon Red, Tetris, Super Mario Land, Zelda e Metroid)
- Inserção/remoção de cartucho apenas com o console desligado

## Como rodar

```bash
yarn
yarn dev
```

Abra [http://localhost:3000](http://localhost:3000).
